# Wie aktualisiere ich die Tools?

Denselben Download-Befehl wie bei der Installation erneut ausführen (README des Templates, „Setup für die Harness“, Schritt 1). Er holt jeweils das neueste Release und überschreibt die Programme im `PATH`. Prüfen: `brain version`, `sharepointcli version`, `qdrantcli version`.
